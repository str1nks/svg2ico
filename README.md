# svg2ico

**Превращает `icon.svg` в готовую иконку `icon.ico` со скруглёнными углами в стиле Windows 11**

Один небольшой скрипт: положили SVG, запустили, получили `.ico` со всеми нужными размерами.

## Что делает скрипт

1. Читает файл `icon.svg` из текущей папки.
2. Рендерит SVG в PNG через [resvg](https://github.com/RazrFalcon/resvg) (пакет `resvg-python`).
3. Масштабирует картинку до **1024 × 1024** (фильтр Lanczos).
4. Скругляет углы маской, радиус составляет 22% от размера. Прозрачность исходного SVG при этом сохраняется.
5. Сохраняет `icon.ico` сразу с набором размеров: **16, 24, 32, 48, 64, 128 и 256 px**.

Такой `.ico` отлично выглядит в заголовке окна, на панели задач, в Проводнике и в трее, а также подходит для сборки программ через PyInstaller (`--icon app.ico`).

## Установка

```bash
pip install -r requirements.txt
```

Зависимости: `resvg-python` и `Pillow`.

## Использование

1. Положите ваш `icon.svg` рядом с `svg2ico.py`.
2. Запустите скрипт **из этой папки**, потому что путь к SVG относительный:

```bash
python svg2ico.py
```

3. Готово, рядом появится `icon.ico`:

```
Иконка icon.ico успешно создана!
```

Если файл `icon.ico` уже существует, он будет перезаписан.

## Настройка

Параметры лежат в начале `svg2ico.py`:

| Константа | Что делает | По умолчанию |
| --- | --- | --- |
| `SIZE` | размер промежуточного изображения в пикселях | `1024` |
| `RADIUS` | радиус скругления углов (`SIZE * 0.22`) | `225` |

- Чтобы **убрать скругление**, поставьте `RADIUS = 0`.
- Для более круглой иконки увеличьте коэффициент, например `SIZE * 0.3`.
- Список размеров внутри `.ico` задаётся параметром `sizes=[...]` в вызове `img.save(...)`. Имена входного и выходного файлов (`icon.svg`, `app.ico`) тоже можно поменять прямо в коде.

## Советы

- **Делайте SVG квадратным** (например, `viewBox="0 0 512 512"`). Картинка растягивается до квадрата 1024 × 1024, поэтому неквадратный SVG будет искажён.
- Рисуйте так, чтобы важное не подходило слишком близко к углам: скругление их обрежет.
- Для максимальной чёткости в SVG лучше задать крупный размер (например, `width="512" height="512"`): рендер идёт в размере, указанном в файле, а затем масштабируется до 1024 px.
